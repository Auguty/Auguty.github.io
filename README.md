# Auguty.github.io

这是“光迹 · 摄影手记”的 GitHub Pages 线上发布仓库。

- 网站地址：[https://auguty.github.io/](https://auguty.github.io/)
- 完整源码：[Auguty/light-traces-photography](https://github.com/Auguty/light-traces-photography)

## 更新网站

请在源码仓库运行：

```bash
npm run release
```

然后使用生成的 `release/index.html` 覆盖本仓库根目录的 `index.html`。

请勿直接修改线上 `index.html`，以免下次发布时丢失改动。
